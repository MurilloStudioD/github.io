DarkStudio

Ferramenta pessoal para criar, editar e agendar vídeos nos meus próprios canais do YouTube.

A personal tool to create, edit and schedule videos on my own YouTube channels.

O que o app faz

  • Envia vídeos produzidos por mim para os meus canais do YouTube e agenda a publicação.
  • Aplica título, descrição, tags e thumbnail que eu defino.
  • Usa a API de Dados do YouTube apenas com a autorização do dono do canal (OAuth do Google).

Privacidade

Os dados ficam somente no computador do usuário e não são vendidos nem compartilhados. Leia a Política de Privacidade.
