Política de Privacidade — DarkStudio

Última atualização: 26 de outubro de 2026

1. Quem somos

O DarkStudio é uma ferramenta pessoal, usada pelo próprio dono para produzir e agendar vídeos nos seus canais do YouTube. Não é um serviço oferecido ao público.

2. Dados que acessamos

  • Conta do YouTube (via OAuth do Google): nome e identificador do canal, e permissão para enviar vídeos e thumbnails (escopos youtube.upload e youtube.readonly).
  • Vídeos e metadados (título, descrição, tags, data de publicação) que o próprio usuário cria no app.

3. Como usamos

Somente para enviar e agendar os vídeos do próprio usuário nos canais dele. Nenhum dado é usado para publicidade, perfil, venda ou qualquer outro fim.

4. Onde ficam os dados

Tudo fica apenas no computador do usuário, com as credenciais cifradas pelo sistema operacional. Não temos servidor e não recebemos cópia de nenhum dado.

5. Compartilhamento

Não compartilhamos dados com terceiros. A única comunicação é com as APIs do Google/YouTube, para executar o que o usuário pediu. O uso de dados obtidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado, e os Termos de Serviço do YouTube.

6. Como revogar o acesso

A qualquer momento em myaccount.google.com/permissions, ou desconectando o canal dentro do app (o que apaga as credenciais salvas).

Privacy Policy (English summary)

DarkStudio is a personal tool used by its owner to upload and schedule videos on their own YouTube channels. With the channel owner's OAuth consent it accesses channel identity and upload permission (youtube.upload, youtube.readonly) only to perform uploads the user requests. All data and credentials stay on the user's own computer (encrypted by the OS); nothing is sent to us or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked anytime at myaccount.google.com/permissions. Contact: murillodominium@gmail.com
